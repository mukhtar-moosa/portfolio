# Project images

Drop your project screenshots/covers here, e.g.:

- project-1.png
- project-2.png
- project-3.png
- project-4.png

Then update the `image` field for each entry in `src/data/projects.ts`.

To render real images instead of the placeholder icon, swap the placeholder
`<div>` in `src/components/sections/ProjectCard.tsx` for Next.js's `<Image />`
component.
